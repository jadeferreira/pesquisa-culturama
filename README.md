# 📚 Pesquisa Culturama

Repositório dedicado ao aprimoramento e consolidação de conceitos fundamentais de desenvolvimento web, servindo como base técnica e laboratório de testes para projetos de maior escala.

O **Culturama** é um projeto prático onde aplico conhecimentos desde a estrutura semântica até a manipulação dinâmica de dados.

## 🎯 Objetivo do Projeto
Consolidar fundamentos de Front-end, garantindo uma base sólida em acessibilidade, SEO e manipulação de estado com JavaScript Vanilla antes da integração com frameworks modernos.

## 🛠️ Tecnologias e Conceitos Aplicados

### 🟢 HTML & CSS (Fases Concluídas)
- **Estrutura e Estilo:** Configuração de ambiente, reset CSS e arquitetura de pastas.
- **Semântica:** Uso correto de tags para melhor indexação.
- **Formulários:** Validação de campos e usabilidade.
- **SEO & Acessibilidade:** Implementação de boas práticas para leitores de tela e motores de busca.

### 🟡 JavaScript (Próximas Práticas)
- [ ] **Lógica de Programação:** Condicionais e Laços de Repetição.
- [ ] **Estrutura de Dados:** Arrays e Objetos.
- [ ] **DOM:** Manipulação dinâmica de elementos e eventos.
- [ ] **Web Storage:** Persistência de dados com `localStorage`.
- [ ] **Integração com APIs:** Implementação de CRUD completo utilizando requisições HTTP (Fetch API).

## 🚀 Evolução do Aprendizado
Este repositório está seguindo o cronograma de práticas:

1.  Ambiente, estrutura e estilo. ✅
2.  Formulários, SEO e acessibilidade. ✅
3.  Lógica de programação com JS. ⏳
4.  DOM, LocalStorage e CRUD. ⏳
